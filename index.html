PUB DEV LOOP

Continuity Template for Persistent Development

Template Overview

This is a generic continuity template for PUB DEV LOOP projects. It provides the minimal documentation and scripts required to enable any project to be resumed, validated, and checkpointed solely from the Git repository.

Key Features

  • Persistence-First Continuity - Repository is the source of truth
  • Master Context Management - Clear project identification and responsibilities
  • Checkpoint Strategy - Record meaningful state changes
  • Resume Strategy - Reconstruct last checkpoint state
  • Runtime Agnostic - No specific provider references

Current State

This repository contains placeholder documentation files that should be customized for concrete projects:

  • PROJECT_HANDOFF.md - Handoff documentation for project continuity
  • PROJECT_STATE.md - Current project state snapshot
  • MASTER_CONTEXT.md - Master context definition
  • README_FOR_AGENTS.md - Agent usage instructions

Development Commands

# Validate project state npm run devloop:validate # Create checkpoint after meaningful changes npm run devloop:checkpoint # Resume on fresh clone npm run devloop:resume
