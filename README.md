# Eletricista Pro - Aplicação para Profissionais Elétricos

Esta é uma aplicação web completa para ajudar eletricistas a gerenciar seu trabalho diário.

## Funcionalidades

- 📊 Dashboard com estatísticas de serviços, clientes e receita
- 💰 Calculadora de orçamento com impostos e descontos
- 📦 Cálculo de materiais (cabos) baseado em distância e tipo de instalação
- 👥 Gerenciamento de clientes
- 🛠️ Gerenciamento de serviços
- 🔢 Cálculos elétricos (Lei de Ohm)

## Tecnologias Utilizadas

- HTML5
- CSS3 (com suporte a dark mode)
- JavaScript Vanilla
- LocalStorage para persistência de dados

## Como usar

1. Abra o arquivo `index.html` em qualquer navegador moderno
2. A aplicação funciona completamente offline
3. Todos os dados são salvos localmente no navegador

## Seções

- **Dashboard**: Visão geral do negócio
- **Orçamento**: Calcule orçamentos para clientes
- **Materiais**: Calcule quantidades de cabos necessárias
- **Clientes**: Gerencie seu cadastro de clientes
- **Serviços**: Registre e acompanhe os serviços prestados
- **Cálculos**: Ferramenta rápida para cálculos elétricos básicos

## Personalização

A aplicação pode ser facilmente customizada modificando:
- cores no arquivo `styles.css`
- adicionando novos tipos de serviço ou cálculo
- ajustando as fórmulas de cálculo conforme necessário
